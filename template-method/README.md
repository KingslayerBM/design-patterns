Шаблонний метод — це поведінковий патерн, який визначає загальний алгоритм у базовому класі, але дозволяє дочірнім класам змінювати окремі його кроки, не змінюючи структуру самого алгоритму. Базовий клас містить метод-шаблон, який запускає алгоритм, а деякі його частини позначені як «гачки» або «абстрактні методи», що мають бути реалізовані в підкласах. Це дозволяє централізовано описати загальну логіку, зберігаючи можливість тонкої кастомізації. Патерн широко застосовується в роботі з фреймворками, системах обробки даних, ігрових циклах та роботі з файлами. Недоліком може бути надмірна залежність підкласів від поведінки базового класу.
