Відвідувач — це поведінковий патерн, який дозволяє додавати нові операції до групи об’єктів, не змінюючи їхніх класів. Класи елементів приймають «відвідувача» через метод Accept(), а потім делегують йому обробку, викликаючи відповідний метод. Це дає змогу винести складні операції за межі класів об’єктів і легко додавати нові обробники, не торкаючись структури елементів. Патерн зручний для роботи зі складними ієрархіями, коли потрібно регулярно додавати нові види операцій (наприклад, аналіз, рендеринг, експорт, логування). Недоліком є складність додавання нових типів елементів — для цього доведеться змінювати інтерфейс відвідувача.
