Команда — це поведінковий патерн, який перетворює запит у самостійний об’єкт. Такий об’єкт містить всю інформацію, потрібну для виконання дії: отримувача, метод, параметри. Завдяки цьому можна передавати команди як об’єкти, ставити їх у черги, зберігати історію, скасовувати й повторювати дії. Патерн відокремлює відправника запиту від об’єкта, який має його виконати, роблячи систему гнучкішою. Найчастіше використовується у меню, кнопках, історії дій, транзакціях та макросах. Недоліком може бути збільшення кількості класів, адже для кожної дії створюється окрема команда.
