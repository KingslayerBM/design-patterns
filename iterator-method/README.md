Ітератор — це поведінковий патерн, який дає змогу послідовно обходити елементи колекції, не розкриваючи її внутрішню структуру. Завдяки цьому клієнтський код може працювати з різними типами колекцій однаково, не знаючи, як саме вони зберігають дані. Ітератор інкапсулює логіку проходження по елементах, що робить колекції простішими та чистішими. Патерн корисний тоді, коли потрібно підтримувати кілька різних способів обходу або коли структура колекції складна. Недоліком може бути збільшення кількості класів, особливо коли кожна колекція має власний ітератор.
