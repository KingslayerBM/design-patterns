Замісник — це структурний патерн, який створює спеціальний об’єкт-посередник, що контролює доступ до іншого об’єкта. Замісник має такий самий інтерфейс, як і реальний об’єкт, тому клієнт не помічає різниці. Його основна мета — виконувати додаткові дії до або після звернення до реального об’єкта: ліниво створювати його, кешувати результати, обмежувати доступ, вести логування, контролювати ресурси або виконувати віддалені виклики. Таким чином, Proxy дозволяє розширювати поведінку без зміни оригінального класу. Недоліком може бути збільшення складності та прихована затримка, якщо замісник виконує додаткову роботу (наприклад, віддалене підключення).
