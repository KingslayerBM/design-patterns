Декоратор — це структурний патерн, який дозволяє динамічно додавати нові функції до об’єкта, не змінюючи його класу. Він «обгортає» базовий об’єкт у спеціальний клас-декоратор, який має той самий інтерфейс, але додає власну поведінку до або після виклику базового методу. Такий підхід дозволяє гнучко розширювати функціональність, поєднувати різні декоратори між собою та уникати створення великої кількості підкласів. Патерн особливо корисний, коли потрібно додати можливості окремим об’єктам без зміни всіх інших. Недоліком може бути збільшення кількості дрібних класів і те, що велика кількість вкладених декораторів ускладнює відстеження виконання.
