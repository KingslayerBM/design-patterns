«Абстрактна фабрика» — це породжувальний патерн, який дає можливість створювати цілі сімейства пов’язаних об’єктів без прив’язки до їхніх конкретних класів. Він визначає інтерфейс для створення набору продуктів, які логічно поєднані між собою та мають працювати разом. Клієнтський код використовує фабрику через абстракцію, завдяки чому легко можна замінити одну сім’ю продуктів на іншу, не змінюючи логіку програми. Патерн особливо корисний тоді, коли потрібно забезпечити сумісність об’єктів або підтримувати кілька варіантів середовищ, наприклад різні теми інтерфейсу чи типи платформ. Головним мінусом є зростання кількості класів і загальна складність структури, але взамін стає можливим централізовано контролювати створення повних наборів взаємопов’язаних елементів.
