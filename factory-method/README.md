«Фабричний метод» — це породжувальний патерн, який дозволяє делегувати створення об’єктів підкласам. Він визначає загальний інтерфейс для створення об’єкта, але дозволяє нащадкам вирішувати, який саме клас слід створити. Завдяки цьому код, що використовує об’єкти, не залежить від їхніх конкретних типів. Патерн особливо корисний, коли система повинна працювати з різними видами схожих об’єктів, але наперед невідомо, який саме тип потрібен. Фабричний метод спрощує розширення програми: щоб додати новий тип продукту, достатньо створити новий клас і перевизначити метод фабрики, не змінюючи наявного коду. Основний недолік полягає в тому, що кількість класів збільшується, оскільки для кожної реалізації потрібен власний фабричний метод.
