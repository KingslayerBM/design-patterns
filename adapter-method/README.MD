Адаптер — це структурний патерн, який дозволяє об’єднати несумісні класи, надаючи одному з них потрібний інтерфейс. Його суть полягає в тому, щоб «обгорнути» об’єкт стороннього або застарілого класу в нову оболонку, яка робить його сумісним із рештою системи. Адаптер працює як перекладач між двома інтерфейсами: клієнт використовує один формат викликів, а реальний об’єкт - інший. Патерн особливо корисний, коли потрібно інтегрувати в систему сторонні бібліотеки або коли новий код має співпрацювати зі старим. Сам адаптер не змінює поведінку об’єкта - він лише перетворює інтерфейс, щоб зробити роботу можливою.
